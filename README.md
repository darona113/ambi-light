# AMBI

Готовый одностраничный сайт без сборки и внешних зависимостей. Все изображения — фотографии готовых работ, предоставленные AMBI. Сгенерированные концепции на сайте не используются. «До / после» удалено по запросу.

## Предпросмотр

Сайт: https://darona113.github.io/ambi-light/ . Для локального просмотра можно запустить `python -m http.server 4173` в этой папке и открыть http://localhost:4173 . Файлы в корне готовы для любого статического хостинга.

## Добавить видео

1. Положите видео MP4 (H.264) в `assets/`, например `ambi-video.mp4`.
2. В `media.js` замените `video: { src: '', ... }` на `video: { src: 'assets/ambi-video.mp4', ... }`.
3. Сохраните и обновите сайт. Вместо анонса появится настоящий плеер с управлением, без автоматического воспроизведения.

## Добавить фотографии

Положите файл в `assets/` и добавьте запись в `photos` в `media.js`: `src`, `title`, `detail`, `category`. Категории: `contour`, `garlands`, `garden`. Для быстрой загрузки рекомендуются WebP шириной до 1600 пикселей. При изменении числа фотографий обновите число возле «Все работы» в HTML.

## Фирменный знак

Сейчас используется временное текстовое AMBI. После согласования нового логотипа замените `.wordmark` в шапке и подвале на SVG/изображение с alt="AMBI". Иконка вкладки также временная.

## Адаптивность

Предусмотрены телефоны от 320 px, планшеты, ноутбуки, мониторы и широкие экраны/TV. Большие экраны используют ограничение ширины контента, повышенные размеры текста и отступов. Есть клавиатурная навигация, управление галереей стрелками, свайпы, фокус в диалогах и режим уменьшенного движения.
