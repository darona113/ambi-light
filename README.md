## Изображения и видео

В портфолио 5 проектов и 11 фотографий. Семь снимков одного дома и участка объединены в один проект. Зимний проект `project-13.webp` удалён из показа по запросу; размытый `project-08.webp` также исключён. Исходные изображения не дорисовывались.

Видео `assets/ambi-in-action.mp4`: H.264/AAC, 720×1280, около 22 секунд, с faststart. Включается по нажатию, при уходе блока за экран приостанавливается. Предзагрузка отключена; обложка взята из видео.

Медиа и описания услуг задаются в `media.js`. Портфолио и примеры услуг перелистываются нативной горизонтальной прокруткой, кнопками и с клавиатуры. У всех услуг есть описания и подписи к фото.

## Служебные страницы

`privacy.html` содержит фактическую информацию о взаимодействии с сайтом и внешними мессенджерами. `404.html` возвращает посетителя на главную. Настроены Open Graph 1200×630, canonical, sitemap и JSON-LD с подтверждённой географией и графиком. Реквизиты, гарантии, сроки, отзывы и числовые цены не выдумывались.

## Локальный просмотр

В этой папке можно запустить `python -m http.server 4173` и открыть http://localhost:4173 . Для публикации достаточно отправить изменения в `main`; GitHub Pages публикует корень репозитория.
